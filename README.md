# Dissertation Template

This repository contains a template of a LaTeX paper that students from the University of Sheffield's School of Computer Science can use as a starting point for their dissertation.

## Prerequisites

Before you can use this template, you'll need to have a [LaTeX distribution](https://www.latex-project.org/get) installed on your machine.
You'll also need some sort of editor.
You could use native LaTeX editors like [TeXstudio](https://www.texstudio.org), but I'd recommend either [VS Code](https://www.google.com/url?sa=t&source=web&rct=j&opi=89978449&url=https://code.visualstudio.com/&ved=2ahUKEwiRtNa5g5uUAxUbZUEAHc36DdEQFnoECBAQAQ&usg=AOvVaw15O90sm1ios8AUpw56hCml) or any of the [JetBrains IDEs](https://www.jetbrains.com).

If using a code editor like VS Code or a JetBrains IDE, you'll need to install the proper plugins to give it LaTeX support.

- For VS Code, I recommend the [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) extension
- For JetBrains IDEs, I recommend the [TeXiFy IDEA](https://plugins.jetbrains.com/plugin/9473-texify-idea) plugin with [PDF Viewer](https://plugins.jetbrains.com/plugin/14494-pdf-viewer)

## Getting Started

To get started, simply clone this repository and open the `paper.tex` file in your LaTeX editor.
This is the "root" file of your paper, but you only really need to edit a few lines at the top to set up your title, name, etc.

You'll want to take a look around the other files `.tex` in the repository, which all include comments to help you understand what they're doing.
There's plenty of resources online about how to use LaTeX if you get stuck.
